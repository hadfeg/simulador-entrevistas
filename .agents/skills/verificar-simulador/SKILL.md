# Verificar simulador

## Propósito

Comprobar que el simulador continúa funcionando después de realizar cambios.

## Procedimiento

1. Iniciar la aplicación.
2. Comprobar que `/` carga correctamente.
3. Iniciar una entrevista.
4. Enviar al menos tres preguntas diferentes.
5. Verificar que el personaje responde.
6. Finalizar la entrevista.
7. Comprobar que se genera la retroalimentación.
8. Revisar que no existan errores visibles en la aplicación.
9. Informar cualquier problema detectado.

No modificar archivos durante esta verificación salvo que se solicite explícitamente corregir un problema.
